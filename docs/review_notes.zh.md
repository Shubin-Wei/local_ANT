# 产品化改动审阅说明

[English](review_notes.md) | 中文

审阅范围为 `main` 上 `23b2361` 之后的改动。提交分别组织基础设施、导出、安装、测试与文档。这些是准备审阅的本地改动，不包含标签、Release 或软件包发布；包版本仍为 1.4.0。

## 已实施范围

- 新工程采用 `work/`、保留成果 `results/` 和内部记录 `.lant/`，提供 README、REPORT 入口。不含旧工程读取或迁移层。
- 默认终端精简输出，程序管理完整日志；stderr 提供进度、已观察到的求解迭代和完成图数。总量未知时显示心跳。
- 产物登记检查、工程锁、带理由的确认、笔记和默认预览的缓存清理使操作可审查。步骤目录存在未登记文件时阻止该步骤覆盖它们。
- `curves.csv` 替代逐台对导出，保持求解器舍入语义；精简配置、默认 PNG、打包编译资源和安装后部署外部程序改善交付体验。
- 中英说明、开发规范、引用元数据、限定范围的检查和格式化、发行包检查支持后续维护。

## 限制与审阅重点

这些是工程验证，不构成新一轮科学验证。本轮没有重跑完整测线求解、随机棋盘、pDSurfTomo 或生产规模压力测试。本地提交尚未触发远程 CI。单元覆盖率不包含独立合成流程。

优先审阅成果交付与失败路径（`delivery.py`、`plotting/figures.py`）、产物归属与清理（`artifacts.py`）、锁和状态（`records.py`、`manifest.py`、`provenance.py`）、CSV 精度（`export.py`）、进程取消（`processes.py`、`inversion/run.py`）和发行包资源。

产物检查采用文件大小及纳秒修改/变更时间，不是内容哈希，也不能识别作者。已测试同一文件系统内移动；复制可能改变元数据并触发提醒。终端标记和确认理由不是身份认证。资源估算不能保证后续负载和未知存储配额。绘图暂存保护渲染失败前的完整文件，但整组多文件替换不是原子事务。

git log --reverse --oneline 23b2361..HEAD
