[English](productization.md) | 中文

审阅基线：`23b2361`（v1.4.0）。在现有分支按单一目的提交，保留审阅历史；实施不意味着对外发布。

## 产物归属

| 产物 | 使用者 | 保留规则 |
|---|---|---|
| 清洗归档、逐小时互相关 | cc、stack | 仅在明确选择清理时视为可重建缓存；原始输入必须仍然可用 |
| 叠加、参考、测量 HDF5 | 测量、质控、诊断 | 默认保留 |
| 反演频散导出 | 初始模型、反演 | 保持实测周期排序、缺测语义和旧版数值舍入 |
| 求解器输入、最终模型、评估、检查 | 评估、绘图、科学审阅 | 交付完整保留副本，不能把整个反演目录当缓存 |
| manifest、配置历史、来源、决策 | 状态、复现 | 保留；状态只有一个权威来源 |

新工程采用 `work/`、`results/`、`.lant/`、`README.md`、`REPORT.md`、配置和按需创建的 `notes.md`，布局身份带版本。这是全新版本，不增加旧工程兼容或迁移层。工程内路径尽量可移动；外部输入不可用时必须说明，不能默认仍可重新计算。

## 科学与操作约束

本轮不改变测量或求解方法、科学默认值、质控判据或第三方随机实现。新配置默认仅 PNG 属于展示行为变化，显式图格式仍受支持。精简配置模板不改变有效默认值。

进度写 stderr，机器输出保持合法 JSON。终端只是显示能力，不证明人类授权。科学确认绑定结果指纹，并记录理由和调用信息。助手必须取得用户的科学决定，不能自创决定。

清理默认预览；执行时取得工程锁，仅删除明确登记的缓存文件，拒绝不安全路径，保留交付成果和未知文件。清缓存后成果仍可读。不引入旧布局读取或迁移命令。

## 验收

新旧版本复用同一份原始合成输入，比较测量网格、接受掩码、拒绝原因和反演输入语义。随机求解检查采用科学诊断，不逐位比较、不添加种子补丁。验证移动、产物缺失、锁、清理、中断恢复、JSON 输出隔离及源码树外安装。最终审阅交接记录实际执行的验证和限制。

## 进度与日志

`lant run ... -v` 显示详细输出。默认将步骤 stdout 写入受管理的 `lant.log`（每份 10 MiB、三个备份），stderr 显示进度与结束摘要。`LANT_PROGRESS=off` 可关闭进度。无法可靠计数的长步骤只输出心跳；完成部分计数任务后才估算剩余时间。

## 笔记、确认与清理

`lant note "内容" -c CONFIG` 追加带时间的笔记。`lant confirm STEP -c CONFIG --reason "决定及依据"` 在同一工程锁下记录结果指纹、理由和调用方式。状态报告未登记、缺失和修改的受管理文件，不推断作者。

`lant clean-work -c CONFIG [--cache archive|cc]` 预览已登记且未变的文件。仅在当前评估完成、原始数据仍可访问时，`--execute --yes` 才执行删除。最终成果和未知文件保留。清理后重建 cc 或 stack 需要重建上游缓存；状态包含 `cache_cleaned`。`--from`、`--rebuild` 显示影响并要求明确确认；重建备份使用独立目录，不覆盖以前的备份。

## 资源预检

clean 在写归档前估算内存和空间，cc 分配任务前再次检查。有效可用内存包括可读取的 Linux cgroup 限制。保留原有 70% 内存余量规则，只调整并发。磁盘按完整输出及替换空间保守估算，不保证未知配额或运行期间的负载。测线使用宽默认速度范围时提前提示，不新增确认关卡、不调整先验。

## 频散汇总表

`work/05_dispersion/curves.csv` 是反演读取表，并保留到 `results/dispersion/`。测量值、质控接受标记、实际反演选择分别记录。独立反演列有意保留原文本精度（周期六位、速度五位、信噪比三位、不确定度五位、坐标八位小数）。`disp.h5` 保留拒绝原因和完整诊断。连续区段筛选与缺测语义不变。

## 安装资源

`lant install-external [dsurftomo|pdsurftomo]` 使用 wheel 和源码发行包内的资源。安装包默认写入 `$XDG_CACHE_HOME/lant/external`（或 `~/.cache/lant/external`），源码工作区使用自身 `external/`；两者都可用 `LANT_EXTERNAL` 覆盖。源码脚本保留为便捷入口。编译输入及既有内存补丁移动至 `lant/_external/`，不改变科学实现。

求解进度在日志可读时显示 DSurfTomo 日志末尾观测到的迭代次数。日志尚未刷新时退回耗时心跳，不把观测到的迭代数当作准确百分比或剩余时间保证。绘图显示已完成任务数。
